# Contributing
Run npm ci and npm run dev. For changes, submit a pull request describing the behavior and validation, and run npm run check. Keep controls keyboard accessible, preserve Unicode Odia and authorial line breaks, and avoid extra services/dependencies.

For book proposals, identify the author, exact edition, source URL, and separate work/edition rights evidence. Follow docs/BOOK_CONTRIBUTION_GUIDE.md. Never label invented examples as authentic works. Correct text only with source evidence and record editorial changes. Content needs maintainer review before publication. Code contributions are MIT; content requires its own compatible permission or rights basis.

This local pilot has no public repository/contact configured. Configure repository issues and a correction/takedown contact before public launch.

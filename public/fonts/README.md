# Font sources and licensing

The bundled font binaries have not been modified.

- `NotoSansOriya.ttc`: copied from macOS `/System/Library/Fonts/NotoSansOriya.ttc`. Its embedded name table identifies Noto Sans Oriya, copyright 2015 Google Inc., and explicitly licenses the Font Software under SIL OFL 1.1. Official upstream: https://github.com/notofonts/oriya. This collection is retained intact; browser support for TTC varies.
- `AnekOdia-Variable.ttf`: copied from the local `isha-workspace/iso_react_v2/packages/fonts/assets/anek/AnekOdia[wdth,wght].ttf`. Its embedded name table identifies Anek Odia, copyright 2021 The Anek Project Authors, and SIL OFL 1.1. Official upstream: https://github.com/EkType/Anek. This TTF provides the portable self-hosted Odia fallback.

The complete license and original embedded copyright notices are reproduced in `OFL.txt`. Font software is separate from the application's MIT license.

Noto Serif Oriya was investigated at https://github.com/google/fonts/tree/main/ofl/notoseriforiya and https://fonts.google.com/noto/specimen/Noto+Serif+Oriya, but binary downloads were blocked in this environment. It is not bundled or claimed as an installed font.
